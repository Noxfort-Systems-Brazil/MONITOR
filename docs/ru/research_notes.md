# 🔬 Журнал технических решений и исследований: Noxfort Monitor™

Документ обобщает архитектурные решения (ADR), тесты производительности и дорожную карту **Noxfort Monitor™**.

⬅️ [Центр документации](README.md) | 🏛️ [Архитектура](architecture.md) | 🗄️ [База данных](database.md) | 🌐 [Удаленный доступ](remote_access.md)

---

## 1. Персистентность: От CGO к архитектуре Dual-Engine
* **Чистый Go SQLite**: Переход на `modernc.org/sqlite` без компилятора C.
* **Dual-Engine (SQLite + PostgreSQL)**: Динамическое горячее переключение на лету через [`DBManager`](database.md).

## 2. Десктоп-интерфейс: От Systray к Wails v2
* **WebKitGTK**: Быстрый рендеринг без нагрузки Chromium/Electron.
* **Режим Headless**: Флаг `--headless` для серверов Linux без дисплея.

## 3. WAN-соединение: DuckDNS + Caddy против туннеля Ngrok
* **DuckDNS + Caddy**: Приоритетная архитектура со встроенным HTTPS и ACME DNS-01.
* **Ngrok**: Резервный туннель для жесткого CGNAT.

## 4. Дорожная карта
* **Федерация серверов gRPC**: Синхронизация распределенных узлов.
* **Предиктивный анализ аномалий**: Модели временных рядов для раннего оповещения.
