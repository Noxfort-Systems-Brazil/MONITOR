## 1. Команды Makefile

| Команда | Описание |
| :--- | :--- |
| `make build` | Сборка десктопного бинарного файла (`bin/noxfort-monitor`). |
| `make run` | Запуск в режиме разработки с графическим интерфейсом. |
| `make run-headless` | Запуск сервера в фоновом режиме Headless (без GUI). |
| `make test` | Запуск полного набора автоматических тестов (Go + Vitest). |
| `make deb` | Сборка установочного пакета Debian (`noxfort-monitor_2.0.1_amd64.deb`). |
| `make install-deb` | Установка или обновление сгенерированного `.deb` пакета через `apt`. |
| `make uninstall-deb`| Удаление пакета `noxfort-monitor` из системы. |
| `make broker-start` | Запуск встроенного брокера MQTT (Mosquitto). |
| `make broker-stop` | Остановка брокера MQTT. |
